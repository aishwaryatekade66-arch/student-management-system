# Student Management System

## Project Overview

This project is a simple Student Management System developed using Java and MySQL. It is used to manage student records through basic CRUD operations.

## Technologies Used

* Java
* MySQL
* JDBC

## Features

* Add student records
* View student records
* Update student records
* Delete student records
* Store student information in MySQL database

## Database

The project uses a MySQL database to store student information.

### Student Table

The main student details include:

* Student ID
* Name
* Course
* Fees
* City

## CRUD Operations

The application supports:

* **Create** – Add a new student
* **Read** – View student records
* **Update** – Modify student details
* **Delete** – Remove student records

## Project Files

* Java source files – Application code
* SQL file – Database and table creation queries

## Learning Outcome

This project helped me practice Java, OOP concepts, JDBC, MySQL, database connectivity and CRUD operations.
